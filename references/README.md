# Images de référence

Ajoute ici uniquement des captures/recadrages que tu as le droit d'utiliser.

Convention :
`references/<building-id>/level-<niveau>/`

Exemple :
`references/cannon/level-21/`

Plusieurs images par niveau sont préférables (angles, décorations proches, résolution différente).
Le moteur de vision pourra ensuite comparer les objets détectés à ces références.
